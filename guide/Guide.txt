# Target - Remove "QS Footer Build ID text"

# The Real Question:
• Can this specific smali logic be done using OVERLAY?
• NO — not with a normal Runtime Resource Overlay (RRO). But Why? 

# Overlays can modify only:
res/values/*, layouts, drawables, dimens, bools, integers, strings.
These are static resources only, not runtime logic.

# Overlays CANNOT:
• Modify or override smali / Java / Kotlin methods
• Change runtime execution flow
• Bypass conditional checks (UserManager, Developer Options, etc.)
• Inject or remove method logic inside SystemUI

This limitation makes logic-level changes like this impossible via RRO.
